# S10 巡逻赛题 · 产业园区全地形巡逻挑战赛（赛道四方向二）

本仓库为云深处科技山猫 S10 轮足四足机器人的全自主巡检方案（作品技术方案见下文）：
SMppi/TMppi 巡航（BodyMPPI + CarVMC）+ RL-Stair 爬梯 + TK1/TK2 交接。
工程口径文档（门控/参数/数据管线，与代码逐行对齐）见
[SMppi_TMppi_Cruise_RL-Stair_TK1_TK2_总方案.md](SMppi_TMppi_Cruise_RL-Stair_TK1_TK2/SMppi_TMppi_Cruise_RL-Stair_TK1_TK2_总方案.md)，
环境安装见 [doc/requirements.md](doc/requirements.md)。

一、任务定义
本作品参加赛道四方向二“产业园区全地形巡逻挑战赛”。赛题要求参赛队伍基于云深处科技山猫 S10 轮足四足机器人平台，在包含坡道碎石、狭窄楼梯、湿滑区域与横脊高架等多种复杂地形的产业园区场景中，使机器人在无人工干预的条件下自主完成多目标点位的巡检任务。该赛题的核心难点在于：巡逻路线同时覆盖连续起伏地形与离散台阶地形，机器人需要在单一任务流程中连续应对两类性质截然不同的运动控制问题，并在保证安全与稳定的前提下尽可能缩短全程用时。
本方案在官方提供的仿真赛道中进行开发与验证。赛道全长约 234 米，沿途设有 33 个航点，其中 30 个为必须依次通过的定位点。机器人从起点出发，每进入一个定位点 0.2 米水平半径即判定通过该点，全部定位点完成后抵达终点停止计时。按照赛题计分规则，最终成绩为完成时间除以模式系数；本队申报自主导航模式，即机器人全程依靠机载感知与自主决策完成任务，模式系数为 1.4。此外，赛题对关节力矩设有安全限制，连续超限超过 0.5 秒即判为不合格，因此方案的力矩合规性与任务成功率与速度同等重要。
系统的输入为机载激光雷达射线测量与机器人本体状态（包括机体位置姿态、关节编码器读数与惯性测量数据），输出为 200 赫兹闭环的十六维关节力矩与轮速指令。从应用价值看，产业园区、变电站与化工园区的自主巡检是四足机器人当前最明确的落地方向之一，本方案所形成的感知、导航与技能切换全栈管线将以开源形式发布，可直接为同类轮足平台的巡检应用提供可复现的技术基线。
二、系统架构
针对赛题地形“连续与离散并存”的特点，本方案采用分层式系统架构，自上而下依次为共享感知层、自主导航层与双管线执行层。其中执行层是本方案的核心设计：我们注意到，巡航段所面对的平地、缓坡与弯道属于连续地形上的轨迹跟踪问题，适合用模型驱动的优化与解析控制方法求解；而楼梯段所涉及的台阶攀爬则是姿态、载荷、接触与步态强耦合的离散接触问题，基于模型的方法难以覆盖全部接触模态，更适合用强化学习策略从大规模仿真训练中直接习得。为此，执行层设计了模型驱动与数据驱动两条管线，由导航层依据地形感知结果在二者之间自动切换，使每类地形都由最适合的控制范式处理。
具体而言，巡航段采用“采样模型预测控制加车化虚拟模型控制”的模型驱动管线：感知层以 4 赫兹增量累积激光雷达高程图，自主导航层与采样优化层同拍以 40 赫兹运行并输出速度指令，底层虚拟模型控制以 200 赫兹输出力矩。爬梯段采用强化学习管线：感知与导航层与巡航管线完全共享，训练所得策略网络以 50 赫兹前向推理，底层以 200 赫兹执行关节位置伺服与轮速控制。两条管线共用同一套激光雷达高程感知与同一条导航参考路径，因而切换发生时机器人的速度、航向与姿态状态是连续的，不存在模式跳变。巡航管线追求速度与跟踪精度，直接服务于计分；爬梯管线追求成功率与鲁棒性，是完赛红线的保障。
三、关键算法与模型
（一）激光雷达高程感知层
感知层利用机载激光雷达的前下向扇形射线（垂直视场加密至 96×48 线）测量地形，将逐帧射线命中点累积到世界坐标系下的栅格高程图中。高程图以 0.05 米分辨率的瓦片增量更新，并辅以运动学先验保证机体遮挡区域的连续性。在高程图之上，感知层沿当前航点方向维持一个最远 8 米的前视扫描窗口（航点不足 8 米时延伸到下一航点），进一步检测台阶立面特征，为导航层提供前方地形的起伏预告；对于赛道中的楼梯区域，系统在线维护一张由激光雷达检测生成的台阶立面表，记录各级台阶的位置与高度，用于提前触发爬梯技能并为强化学习策略提供地形上下文（不依赖任何已知地图硬编码）。该设计借鉴了苏黎世联邦理工学院的栅格高程建图方法（Fankhauser 与 Hutter，ICRA 2016），并与轮足机器人领域公开的激光雷达地形感知实践保持一致。
（二）自主导航层
导航层直接以 33 个航点的原始折线为参考路径（相邻航点直线段，不做圆角与样条平滑），保证参考路径与赛题判点口径严格一致，避免弯道切角造成的横向偏差。在此基础上，导航层在线生成速度剖面：接近航点时按剩余距离的平方根剖面平滑刹停，并由采样优化层的航点终点代价二次兜底；对横脊、高架与窄脊等危险区域按激光雷达高程分档限速；接近楼梯区域时按在线检测的立面表平缓降低速度，为爬梯交接做准备。在线运行时，导航层维护一个沿路径单调推进的弧长游标，通过切线投影抑制过弯时的切角误差，并按赛题口径严格执行定位点判定（0.5 米判点半径、过点兜底与航向/角速度对准门防抢跑）。该层的方法渊源包括 Coulter 1992 年的 Pure Pursuit 路径跟踪算法，以及 Fox 等人 1997 年提出的动态窗口法所确立的速度空间限速思想；早期版本曾采用 Catmull-Rom 样条平滑，现行版本按判点口径改回原始折线。
导航层同时负责巡航与爬梯两种技能的切换决策。当高程图在机器人前方 8 米扫描窗口内检测到连续台阶立面（至少两级、跨度不超过 3 米、总爬升不低于 0.2 米），或单级不低于 10 厘米的台面沿，且机器人进入首级立面 1.2 米内的交付圈并满足航向、速度与航线夹角门控时，系统从巡航模式切换至爬梯模式；当四轮全部越过最高一级立面且姿态与速度收敛时，系统判定攀爬完成，平滑降回巡航模式。切换的进入与退出均采用渐近式速度与姿态过渡，避免控制量突变破坏机体平衡。
（三）巡航执行层：采样模型预测控制与车化虚拟模型控制
巡航管线的上层为采样式路径积分模型预测控制（MPPI）。该方法在每一步围绕当前状态随机采样 1024 条候选速度序列，在 2 秒视界内滚动仿真其对应的机体运动轨迹，再按代价函数的 softmax 权重对候选序列加权平均，得到最优的速度指令。代价函数综合了到目标点的距离、速度偏差、航向偏差与控制平滑性，并附加航点终点代价保证到点速度归零；采样过程施加摩擦锥硬约束，即线速度与角速度的乘积不超过摩擦极限，从机理上保证机器人高速过弯时不发生侧滑。该层以纯 NumPy 实现，在普通 CPU 上即可达到 40 赫兹实时（实测单次规划约 10 毫秒）。方法上承袭 Williams 等人 2016 年提出、2017 年完善的 MPPI 框架，并参考了 DIAL-MPC 将采样优化引入腿足机器人控制的公开工作。
巡航管线的下层为车化虚拟模型控制（CarVMC）。该方法将轮足机器人抽象为“车轮负责驱动与转向、腿负责悬架与姿态”的虚拟模型：车轮侧按航向误差的比例-阻尼律进行差速转向，并根据各轮实时载荷动态钳制驱动力，防止附着力饱和；腿侧以虚拟弹簧阻尼实现主动悬架，在静态重量分配的基础上叠加横滚与俯仰方向的载荷转移，并通过半蹲姿态降低质心；对巡航中必经的骑坎与小台阶，执行锁存冲量与抬轮前馈辅助通过。整套控制律对地形变化连续响应，仅保留少量针对骑坎与下落沿的安全门控，因而具备良好的可解释性与工程稳定性。其理论基础为 Pratt 等人 1997 年提出的虚拟模型控制与 Sentis 与 Khatib 2005 年的全身分层控制框架，轮足平台的高速转向设计参考了 RA-L 2024 年发表的 SKATER 机器人工作。
（四）爬梯执行层：大规模并行强化学习
爬梯管线采用近端策略优化（PPO）算法训练的策略网络。训练采用非对称演员-评论家结构：演员网络仅使用与部署时完全一致的五十五维本体感知观测（包括机体角速度、重力方向、运动指令、关节误差、关节速度、上一时刻动作、航向与台阶地形上下文），评论家网络在训练时可使用仿真特权信息，从而兼顾部署可行性与训练效率。策略的动作为十六维关节位置目标与轮速目标，部署时经固定的关节伺服与轮速控制环执行。训练基于 MJX 引擎在 GPU 上并行运行 1024 个仿真环境，数小时即可完成一轮课程。
为保证策略在真实赛道几何上的可靠性，训练采用课程学习与域随机化相结合的策略。课程从平地行走开始，依次经历单级台阶（5 至 12.5 厘米）、四级阶梯，直至比赛的六级楼梯（首级 0.061 米、后续五级各 0.125 米、踏面 0.4 米），最终在包含交接扰动的完整赛段上收敛。域随机化覆盖关节伺服增益、扭矩输出、机体质量、地面摩擦、观测噪声、入梯角度与轮驱增益，其中轮驱增益按 0.3 至 1.2 倍随机化，专门用于覆盖我们在迁移实验中发现的仿真间 2.7 倍轮驱差异。该方法体系直接对标 Chamorro 等人 ICRA 2024 年发表的轮足机器人盲爬楼梯工作，训练框架承袭 Rudin 等人 CoRL 2022 年开源的大规模并行强化学习范式。
巡航与爬梯之间的交接是本方案工程实现的关键一环。实验证明，轮足机器人攀爬台阶需要保持足够的前进动量与收敛的腿部姿态。因此交接流程设计为：巡航管线带速接近楼梯，接近过程中由减速请求与终点代价平滑降速至 1.5 米每秒的交付速度，并以关节伺服缓慢抬高机身使腿部误差收敛（PRETRANS 距离式预交接），车轮保持转动不停车，随后强化学习策略在动量充足的条件下接管攀爬，爬完最后一级后按交接距离平滑降回巡航半蹲姿态。整个交接过程的速度、航向与姿态均为连续过渡，无急停或阶跃。
四、部署与复现
本方案的全部软件在 Ubuntu 24.04 与 ROS 2 Jazzy 环境下开发，主要计算依赖为 MuJoCo 物理仿真、JAX/MJX 并行训练框架、PyTorch 策略推理与 NumPy（仿真激光雷达使用 MuJoCo 原生射线接口实现），详细安装步骤收录于仓库的 doc/requirements.md 文档。仿真复现方面，仓库提供主链路一键运行脚本，支持无窗口批量运行与轨迹导出，便于评委直接复核结果。
强化学习部分的复现链路完整封闭：训练脚本、课程配置、环境定义、评估脚本、策略导出工具与部署控制器均收录于仓库 rl_stair 目录。部署端观测编码与训练端逐位一致（数值差异约 3.7×10⁻⁹），策略以 TorchScript 格式导出，支持不同检查点之间的快速切换对比。仓库另附两个独立的仿真间验证工具，分别在精确比赛几何的简化环境与官方真实赛道模型中对策略进行定量验收，用于隔离训练引擎与部署引擎之间的差异。面向真机迁移，方案的感知、导航与控制分层与仿真完全一致，仅需将传感器驱动与底层执行接口替换为官方二次开发接口，相关硬件资料已收录于仓库 doc 目录。

需要向评委如实说明的是，方案目前仍存在明确的边界：最新集成轮次已首次通过航点 14，当前代码为新一轮基线（高程扫描窗口 v2 与巡航减速强化），航点 10 微升段等后续赛段仍在联调，全程 33 航点连跑与真机迁移是下一阶段的工作重点。此外，在开发早期我们曾将仿真中“趴地爬行”通过台阶的现象误判为验收达标，后续排查确认其根因是训练引擎与官方赛道模型之间约 2.7 倍的轮驱增益差异，相关更正规已完整记录于仓库技术文档；针对该根因设计的域随机化修复后，最终锁定的策略在课程末段的成功率为 0.649，并实现了真实赛道模型上直立爬完全部六级的结果。巡航段与爬梯段的仿真演示视频随代码仓库一并提交，作为上述结果的过程性证据。
