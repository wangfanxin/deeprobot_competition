## 2. 高程图 STAIR 模式判定（验收核心，已实现+单测通过）
- **入口（CRUISE→STAIR）**：auto_nav `_elev_stair_ridge_ahead` 沿航向扫高程图 step_flag（台阶/横脊边缘）0.5~4m →
  按接近度生成 `decel_request`（巡航 vx 向 S10_ELEV_DECEL_VX 默认 1.2 ramp）→ 进入 STAIR。
- **出口（STAIR→CRUISE）**：`_elev_region_passed`（高程图前方 0~3m 无 step_flag=已越过）优先；
  固定坐标（next_idx>7 / y>40.5）仅无高程图时兜底（修复：有图时 y>40.5 不再提前切出）。
- **接线**（cruise_vmc_noros.py，S10_RL_ELEV=1 启用，默认关=零回归）：
  - LidarTerrainV2 → `elev_tile.build_local_tile` 构建 local_map（heightmap/valid/step_flag）
  - `fol.update_mode(..., local_map=_lm)` + `fol.decel_request` 应用到 vx
- **rlstair 部署控制器**（rl_stair/deploy/rlstair_ctrl.py）：obs_np(55) → policy.pt → 腿 PD(50/1/clip48)+轮速(kp2/vel24/clip13.5)，riser 表外部注入。
- **单测**：合成高程图 4 例（2m 前减速 0.8 / 1m 前进 STAIR / 越过回 CRUISE / 未越保持 STAIR）全部通过。

## 8. 全流程集成诊断（2026-08-16 00:55）
- **RL 技能独立验收**：官方环境 spawn_y=34（RL 交接点）+ RL 直接驱动 = **96.7% (29/30)**（§7）。
- **全流程 cruise→RL→cruise**（cruise_vmc_noros + rlstair 双模式 + S10_RL_ELEV=1）：栈可运行，模式切换/减速生效（cmd vx 2.5→1.8），但 **wp6→7 接近段 cruise(CarVMC) 行为差**（轮速负值 -0.25..-0.9、yaw 漂移 1.67→-2.75）→ 带病状态交给 RL 后无法恢复，在楼梯处侧翻。直连 nav 与 MPPI 两种模式均复现。
- **结论**：RL-stair 技能本身官方环境已验证（96.7%）；全流程卡在 **cruise 本段接近调优**（CarVMC 对 wp6→7 交接段的姿态/轮速控制），属 cruise 控制器调优范畴（非 RL 技能缺陷）。
- **lidar 感知限制**：LidarTerrainV2 射线模式（下倾 40°）只能看到近距离（~1.5m）地形，前方 4m 楼梯看不到 → 高程图确认仅近距离生效；远程检测需靠已知地图全局触发（已接线）。
- **待办**：① cruise 接近段调优（或从 wp5 完整巡航进入让 CarVMC 进入稳态）；② 若需远程高程图检测，调整 lidar 射线仰角范围。
