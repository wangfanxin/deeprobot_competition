# S10 巡航 CarVMC 方案 · 数据管线 · 逐层配置（2026-08-10）

> 本文档为当前（2026-08-10）巡航技能的实现快照：方案、数据管线、每一层的
> 设计考虑与参数。台阶技能（wp6→7）与 70s 目标进展见 doc/0808.md §44 系列。
> 原则：**除 cruise/stair skill 切换外不使用门控**——地形/抬轮/限速全部用
> 连续几何量或连续安全包线驱动。

## 1. 总方案（双技能）

| 技能 | 方案 | 说明 |
|---|---|---|
| 巡航（平地+缓坡+横脊） | 导航 →（身体层 MPPI，可选）→ **CarVMC** | 车化：轮驱动/差速转向 + 腿=主动悬架；无门控、连续地形响应 |
| 台阶（wp6→7） | 同一腿层 + **几何相位步态** | 已知楼梯几何按弧长调度前/后轴抬放（skill 切换门控） |

架构分层：
```
mujoco (S10_track.xml / new_wp30.xml)
  → mujoco-lidar (64×32 扇形, 前下45°, 10Hz)
  → LidarTerrain 世界栅格累积高程图（SLAM式, 10Hz）
  → AutoNavFollower（20Hz）: 平滑路径 + 速度剖面 + 判点 → [vx, ω]
  → BodyMPPI（可选, 20-30Hz）: 1.0s 视界轨迹优化（约束在摩擦锥）
  → CarVMC（200Hz）: 轮驱动/差速 + 腿主动悬架 + 连续前瞻抬轮
  → mujoco 200Hz
```

## 2. 数据管线（部署同款，lidar）

1. **mujoco-lidar**：`lidar_site`（base 上方 0.15m，前下 45° 安装），扇形射线
   64×32，垂直 +10°~-55°，cutoff 20m，10Hz。
2. **LidarTerrain**（vmc_legs.py）：世界坐标固定栅格（x[-25,40] y[-5,55]
   res=0.1），命中点 min-z 累积（跨帧累积、抗噪），geomgroup 只留 group 0
   （地形，排除机器人/赛道标记）；未覆盖格返回 0（近场盲区）。查询 O(1)。
3. **AutoNavFollower**（20Hz）：见 §3.2。
4. **BodyMPPI**（可选）：见 §3.3。
5. **CarVMC**（200Hz）：见 §3.4。

## 3. 逐层配置 / 考虑 / 参数

### 3.1 感知 LidarTerrain

| 参数 | 值 | 考虑 |
|---|---|---|
| 栅格 | x[-25,40] y[-5,55] res=0.10 | 覆盖全程 |
| 射线 | th_n=64, phi_n=32 | 近场地面到远场高台 |
| 累积 | 世界坐标增量，min-z | SLAM 式；局部栅格每帧清空会丢数据（起步卡死根因，v223） |
| 盲区 | 未覆盖格返回 0 | 真机近场盲区同款；横脊处阴影可能缺数据 → 抬轮由连续前瞻兜底 |

### 3.2 导航 AutoNavFollower（20Hz）

**路径**：Catmull-Rom 平滑路径严格过 33 航点（偏差 0.013m），切线因子
`S10_GLOBAL_TANGENT_K`（0.7 弯道半径 1.36→2.1m+）。

**速度剖面 path_vlim**（沿弧长预计算）：
- 曲率限速 `v=√(S10_AUTO_LAT_ACCEL·R)`（当前 3.5，实测包线）
- 转向能力 `v ≤ S10_AUTO_OMAX·R`（当前 2.0，宽松；实际由执行层包线约束）
- 急转弯 `S10_AUTO_SHARP_TURN_VX`（3.5）、S 弯组合 `S10_CURVE_SWING_VX`（3.5）
- 横脊 `S10_RIDGE_VX`（1.5~2.5，保守）、台阶 `S10_AUTO_STEP_VX`（1.5）
- 高架 `S10_AUTO_ELEV_K`（0.2，z 越高限越狠）
- 运行时减速前瞻 `S10_AUTO_VLIM_LOOKAHEAD`（2.0~3.5m，进弯速度包线关键）

**目标选择**（v267/v271/v272）：
- 接近航点（d_wp<0.8）瞄航点（可关 S10_AUTO_WP_AIM_ON=0）
- 过点后（passed）瞄**路径前视点**（v267：修"回头瞄当前航点→err 饱和
  振荡→漂西"；AIM_AHEAD=1 可选瞄下一点，S 弯会切弦不推荐）
- cte 纠偏：仅当 |cte|<S10_AUTO_CTE_MAX(0.5) 且与 err 不冲突时叠加
  （v272：离线恢复时丢弃 cte 让前视转向主导，防 cte/err 抵消不转）

**判点**：`S10_WP_ADVANCE_DIST=1.0`（位置式）；v253 过点后强制 s_cur 前进。

**输出**：`vx`（vlim 窗口 min + err 分级）+ `vyaw`（yaw_gain·err + yaw_ff −
yaw_damp·yaw_rate + cte_corr，slew 0.8/s，clip ±S10_AUTO_VYAW_MAX）。

### 3.3 身体层 MPPI（可选，S10_VMC_USE_NAV=0）

| 参数 | 值 | 考虑 |
|---|---|---|
| N / H / dt | 256 / 20 / 0.05 | 视界 1.0s；纯 numpy <5ms，20-30Hz CPU |
| τv / τw | 0.15 / 0.10 | 闭环一阶滞后（标定） |
| μ | S10_MPPI_MU=0.36 | 摩擦锥 ω≤μg/v ↔ a_lat=3.5（与 CarVMC 实测一致） |
| 采样中心 | guide_vx=v_ref, guide_om=κ·v_ref | v270：曲率前馈（赛用摩托恒定转向率），样本围绕正确转向 |
| cost | w_dist·d_min + w_h·h_err² + w_v·v_err² + w_s·‖Δu‖² | 贴路径+跟航向+跟限速+平滑 |
| DBaS | ada_alpha 0.35, σ∈[0.5,2.0] | 卡约束放大探索 |

约束在 rollout 内（摩擦锥 clip），**不在导航层**——导航给参考、MPPI 算安全
轨迹（用户架构点，v269/v270 落地）。注意：导航不能全放开（MPPI 1.0s 视界
补不了进弯刹车），导航保持带包线的参考剖面。

### 3.4 CarVMC 执行层（200Hz）

**轮**：
- 差速参考 `v_ref = vx ± ω_ref·track_half`，**ω_ref 用即时指令**
  （v252：低通 _om_f 方向翻转滞后 0.3s → 过冲侧翻，改用即时）
- `t_yaw`：比例 `-yk·(ω_cmd−ω)` + 高频阻尼 `kd·ω_hf`（v237/v244，body 系
  yaw 率 + 高通） + 可选摩擦前馈 `S10_CAR_YAW_FF`（v241，默认 0）
- yaw 超速保护（v249/v251）：|ω|>S10_AUTO_LAT_MAX/v 时差速参考反向硬刹
  + 阻尼+8（实际转速超包线即刹，非只限指令）
- 力矩限速 `S10_CAR_YAW_SLEW=30 Nm/s`（v246，防过冲瞬态）
- 差速滑移余量 `S10_VMC_YAW_TMAX=8`（v244：允许差速力矩超牵引极限做
  受控滑移转向；驱动分量仍受 μN·r 钳制）

**腿（主动悬架）**：
- 垂直力 `F = mg/4 + roll分配 + pitch分配 + 地形阻抗 kp_h·(terr+r−wheel_z)`
- 姿态 PD 半蹲（S10_CAR_SQUAT=1，knee 1.90 降质心 ~6cm）
- 微 roll 压弯 `roll_tar = −0.06·ω·|vx|`（±0.06）

**连续前瞻抬轮（v264-v266，无门控）**：
- 按"轴前 S10_VMC_LIFT_LOOKAHEAD(0.35m) 地形高 − 轴下地形高"连续抬放
  （前轴/后轴分别），比例 clamp 0.15m
- 上升量带通 v265：只响应 0.02~0.5m 可爬台阶（0.12m 脊→满抬，高架 2m
  伪尖峰→0，连续光滑无硬阈值）
- 抬轮前瞻独立于 terr 前瞻（v266：terr 前瞻 0.5 在起步坡阻抗过激）

**轮力矩钳制**：`_wt = μ_w·F_load·r + YAW_TMAX·f(ω_cmd)`（μ_w=0.9；驱动受
牵引极限，差速按滑移余量放大到执行器上限）。

### 3.5 台阶技能（skill 切换）

- 楼梯区近距门控 v248（首脊前 1.0m ~ 末脊后 2.0m，skill 切换）
- 几何相位抬放：按已知楼梯弧长窗口调度前/后轴（v236/v238）
- 抬放姿态 FK 验证：前轮抬 0.141m、后轮抬 0.144m（够 0.125m riser）
- 未验证（wp6→7 尚未到达）

## 5. 当前状态与卡点

- **wp0→4 ≈ 19~20.5s 干净**（S 弯稳定：v249-v252 yaw 修复 + VLIM_LOOKAHEAD
  进弯速度包线 + v267 过点瞄路径前视 + v272 离线 cte 丢弃）
- **wp4→5 卡点**（~42 次配置）：狗切 wp3→4 弯后偏东 0.9m、航向冲突
  （cte 拉左/err 拉右抵消→不转→漂西→脊基卡死）；v272 修复待验证
- **台阶未验证**（未到达 wp6→7）
- **速度**：当前均速 ~1.5（限速保守），目标 70s 全程均速 3.35
- **70s 理论路线**（离线扫描）：OMAX≥2 + 急弯/横脊/近点放开 → 70.4s；
  需要 yaw 权威（滑移余量已证 3.6 rad/s 可达）+ 台阶技能
