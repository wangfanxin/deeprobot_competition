# Stair 技能当前方案总结（2026-08-12，HEAD `05f1416`）

> 目标：真原图 wp6→7 连续越过全部 6 级台阶（riser 高 0.061 + 0.125×5）。
> 现状：接近段稳定、前轴动量滚过 riser1、到达 riser2 棱口（y=38.3）；
> 卡点：body 塌陷死举（见 §五）。

## 一、方案总览：位置基全身控制（论文方向，无 MPPI）

三层架构 + 双技能门控（唯一离散切换）：

```
CRUISE（CarVMC） ⇄ STAIR（StairWBC 位置基全身控制）
       技能切换：fol.mode == 'STAIR' 且前轴距首级 riser < S10_STAIR_EXEC_D
```

**StairWBC 执行层**（`src/S10_sdk_deploy/s10_mpc/stair_wbc.py`，200Hz）：

1. **ModeSchedule**：整轴布尔相位（前轴→后轴，永不双轴同抬）——几何相位硬切换，sin² 仅生成位置目标；
2. **Body 姿态解析 + FootPlaceVMC 位置 PD**：每腿闭式 IK 放轮 + 静压；
3. **WheelCtrl**：支撑轮速度 PID 前驱（爬升期冻结差速、前驱下限 -6Nm），抬升轮 0；
4. **QP Checker**：osqp 12 变量接触合规校验（摩擦锥/法向下限），仅破锥时微降腿增益，非力分配主环；
5. **腿控 Yaw**：HipX 外展/内收修正航向（轮差速冻结时唯一 yaw 权威）。

**已清理**（用户要求）：所有 `S10_STAIR_*`/`S10_QP_*` 散落 env 收敛为类属性；
删除 `S10_STAIR_SWING_WHEEL0` 状态翻转、`S10_STAIR_QP/FACE` 开关门控；
修复 QP Checker 未初始化 rows/cols/vals/lo/hi 的 NameError（此前从未真正运行）。

## 二、数据管线

```
感知层（10Hz）
  lidar 高程图 + stair_world 预扫描（riser 表：y/top/dh，世界坐标）
  → 几何地形 _geo_terrain（每轮支撑面高 = 已过最高 riser 顶 / 最近 riser 底）
规划层（20Hz, AutoNavFollower）
  纯 xy 路径跟踪（Catmull-Rom），vx 连续插值（楼梯窗不归零）
  → cmd: vx / omega / yaw 误差（_last_err）
执行层（200Hz, StairWBC.compute_tau）
  ModeSchedule → 贴面目标 _face_place_z → 闭式 IK → 位置 PD + 静压
  → WheelCtrl（速度 PID ±13.5Nm）→ QP Checker → 腿控 Yaw
  → 16 维力矩（腿 ±48Nm / 轮 ±13.5Nm）
```

## 五、卡点与根因

**唯一卡点**：接近段 body 塌陷到 0.63（正常 0.78）→ 腿近乎水平（垂距 1cm）
形成"死举"几何死点 → 前轮无法抬过 riser2 → 卡死 → yaw 漂移翻车。

**根因**：FootPlaceVMC 位置控制靠轮目标间接实现 body 高度（bdes_z），
而水平腿伸长的力是水平的（轮前滚），无法把 body 举回。body-z 闭环存在
塌陷平衡（body 低 → 轮目标低 → bdes_z 低 → 接受低 body）。
所有参数/力项尝试（BODY_K、STAND_DROP、PRESS、直接上举力、bdes_z 几何化）
均无法打破该几何死点。
