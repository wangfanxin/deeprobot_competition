# DIAL-MPC 巡航方案（重设计 2026-08-17）

## 核心原则
- DIAL-MPC 全程同一组参数，不做 CRUISE/STAIR 内部模式切换。
- 路径规划输出的 path_pts 是最高优先级参考，默认严格跟踪 path。
- 只有检测到真实障碍物/楼梯时，才做避障或 TK 切换。
- 不做 wp 之间的分段参数堆叠。

## 技能划分
- 巡航：nav + DIAL-MPC CRUISE（全路径同参数）
- 障碍物：DIAL-MPC cost 中的 wall/obstacle 距离场
- 楼梯/横脊：
  - TK1：楼梯前对齐 + 减速
  - 楼梯执行：RL-stair
  - TK2：四轮过最高 riser 后切回 CRUISE

## 参考路径
- `AutoNavFollower.path_pts` 为平滑 path plan。
- 巡航目标点 = 当前 `s_cur + lookahead` 的 path point。
- 允许避障时偏离 path，但无障时必须贴 path。
