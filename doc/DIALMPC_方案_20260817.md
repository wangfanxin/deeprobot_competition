# DIAL-MPC 方案（用户指定 2026-08-17）

## 方案
- 巡航：nav + DIAL-MPC（`s10_mpc.auto_nav.AutoNavFollower` + `s10_mpc.mpc_controller.MPCController`）
- 切换：TK1 / TK2
- 楼梯/横脊：RL-stair（`rl_stair/deploy/rlstair_ctrl.py`）
- 巡航避障：**直接加入 DIAL-MPC rollout cost**（不再使用 BodyMPPI 额外层）

## 入口
- 主脚本：`src/S10_sdk_deploy/scripts/stair_dial_noros.py`
- 启动脚本：`run_dialmpc_stair_wp033.sh`
- DIAL-MPC 障碍 cost：`src/S10_sdk_deploy/s10_mpc/mpc_controller.py`
  - `set_obstacle_costmap()`
  - `update_state()` 注入 `obstacle_d / origin / res / dmax`
- 障碍代价采样与 reward：`dial-mpc/dial_mpc/envs/s10_env.py`
  - `_sample_distance_field()`
  - `_reward_pure()` 中的 `r_obstacle`

## 已禁止/移除
- `s10_mpc.body_mppi.BodyMPPI` 不再用于巡航避障。
- 已知地图横脊预扫描 `S10_RIDGE_PRESCAN` 默认关闭。

## 当前关键参数
- 单级楼梯感知：`S10_ELEV_MIN_STEPS=1`, `S10_ELEV_CLIMB_TH=0.10`, `S10_ELEV_STEP_TH=0.08`
- 楼梯进入：`S10_STAIR_ENTER_DIST=3.5`；减速窗口：`S10_ELEV_ENTER=5.0`
- 巡航 yaw：`S10_AUTO_YAW_GAIN=2.5`, `S10_AUTO_VYAW_MAX=2.0`, `S10_YAW_DAMP=0.5`
- 巡航路径跟踪：`S10_AUTO_LOOKAHEAD=2.0`, `S10_CTE_GAIN=5.0`, `S10_AUTO_CTE_MAX=2.0`, `S10_AUTO_CTE_ERR_GATE=1.2`
- 巡航速度：`S10_AUTO_VMAX=4.0`
- DIAL-MPC：`S10_MPC_NSAMPLE=512`, `S10_MPC_HSAMPLE=14`, `S10_MPC_NDIFFUSE=1`
- 楼梯：TK1/TK2 与 RL-stair；TK2 改为“四轮越过最高 riser 后切回 CRUISE”
