## 三、剩余墙（roll）机制

```
前轮上 riser2（高）+ 后轮在 riser1（低）→ body 俯仰 -0.4
→ yaw 漂移（1.15→0.92）+ 非对称接触 → body 滚转 1.16
→ 左侧轮被带起（前左 1.0）→ 支撑多边形变窄 → 翻
```

roll 控制权威受限于：轮距 0.48m、合规力矩 48Nm、爬顶期窄支撑。增益类方案全部更差/无效。
