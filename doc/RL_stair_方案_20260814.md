# RL-Stair 技能方案（定稿）

> 状态：已定稿并全部落地——训练、导出、部署控制器、官方环境验收、wp0→33 主链路集成均已完成。

## 1. 定位
- 统一一个 RL 策略负责全部台阶爬升（楼梯专用：去横脊、T6 纯楼梯交接）。
- 训练栈 MJX（与比赛同一 MuJoCo 物理）；文件全部隔离在 `rl_stair/`，不改比赛 XML 与既有源文件。

## 2. 部署架构
```
lidar 高程图 → riser 特征 → 策略观测编码(55)
IMU/关节状态 → proprio ────────────────┘
                  ↓
  RL 策略（50Hz, 16D）→ 腿位置 PD + 轮速度闭环（200Hz）→ MuJoCo
```

## 3. 训练配置（定稿值）
- 动作（16D）：腿位置目标×12（action_scale 0.25）+ 轮速度目标×4（vel_scale 24）。
- 观测（55 维）：angvel×0.25(3) | gravity(3) | cmd vx/yaw(2) | leg_err(12) | leg_vel×0.05(12) |
  last_action(16) | heading[cos,sin](2) | terrain_ctx(4) | rough(1)。
- 奖励：velocity-tracking 主奖励（lin 4.0 / ang 2.0 / σ0.25）+ 位置制（progress 4.0、riser 3.0、
  goal 10、speed 2.0、heading 2.0）+ 姿态/高度/力矩/动作率/限位/髋 L2 正则 +
  4 项爬梯专项 shaping（见 `doc/RL_stair_奖励增强_4项_20260815.md`）。
- PPO：非对称 actor-critic（clip 0.2、entropy 0.003、epochs 5、minibatches 4、γ0.99、λ0.95），
  only_positive_rewards；critic 特权含真实接触力（×0.01、clip ±5）。
- 课程（11 阶段）：T0 平地 → T1a/b/c 单级渐进 → T2a-e 排台阶 → T3 比赛六级（门槛 0.6）→
  T6 纯楼梯交接（yaw ±1.0、vx −0.5..2.5、spawn 0.5..2m）。
- 训练地形与比赛几何一致：riser 0.061+0.125×5、tread 0.4m。

## 4. 部署与验收
- 导出：`torch.jit` forward() 确定性导出 `deploy/policy.pt`（round-trip 误差 0.0）。
- 部署控制器 `rl_stair/deploy/rlstair_ctrl.py`：policy.pt + 腿 PD(50/1/clip48) + 轮速(kp2/vel24/clip13.5)，
  riser 表由 lidar 在线注入；观测编码与训练逐位一致（diff 3.7e-9）。
- 官方比赛环境验收：**96.7%（29/30 seed）**，wp6→7 平均 7.96s（见 `doc/RL_stair_最终验收_20260815.md`）。
- 主链路集成：SMppi/TMppi 巡航 + TK1/TK2 楼梯交接 + RL-Stair 台阶段，wp0→33 全链贯通。
