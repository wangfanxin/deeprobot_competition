# Stair 区域判定与技能切换计划（2026-08-11）

> 状态：**计划待审**
> 上游方案：[stair_StairWBC_终版_20260811.md](stair_StairWBC_终版_20260811.md)（执行层终版）
> 本文件补充"**区域判定 + 技能切换**"：何时判定进入楼梯区并启用 StairWBC、爬完后何时切回 CRUISE、切换过渡如何连续。

## 一、目标与约束

- 目标：楼梯段自动进入 STAIR（启用 StairWBC），爬完自动回 CRUISE，全程不人工干预。
- 约束：
  1. **唯一允许的离散门控 = CRUISE/STAIR 技能切换**（StairWBC 内 ModeSchedule 布尔相位是几何实现，不算门控）；
  2. **禁止 z 先验**：航点 z 升不能作为触发依据，感知确认来自 lidar 高程图 step_flag；
  3. **vx 连续**：进入/退出窗内插值，不归零、不跳变；
  4. **世界坐标化**：判定不依赖 s_cur 弧长投影；
  5. **滞回防抖 + 换地图鲁棒**。

## 二、技能状态机

```
CRUISE ──(入口判定通过)──> STAIR ──(出口判定通过)──> CRUISE
   ▲                                                     │
   └──────────────── 滞回保持（不因单帧失败退出）────────────┘
```

- 状态：`mode ∈ {CRUISE, STAIR}`，由 `update_mode` 维护；
- STAIR 内：ModeSchedule 布尔相位运行（前/后轴整轴抬放），StairWBC 执行；
- CRUISE 内：CarVMC 执行，不读楼梯几何。

## 三、入口判定（CRUISE → STAIR）

**主判据：lidar 高程图感知确认（终版）**

- lidar 高程图（10Hz 世界栅格，已有）派生 `step_flag`：近水平面（法向 nz 过滤已有）上，前方 0.3~1.5m 窗口内相邻格高度差 ≥ 0.08m 的离散上升沿 ≥1 处；
- 窗口沿当前 yaw 前方取样（复用 `_stair_confirmed` 逻辑——该函数已写好，但主循环未传 local_map，属死代码，需接线）；
- 连续 2~3 帧确认 + 滞回，防单帧噪声。

**辅助判据：已知地图预扫描（仅候选/提前量）**

- riser 预扫描表（stair_world 世界坐标）y 窗口命中 + 到楼梯段首距离 < `S10_STAIR_ENTER_DIST`（默认 1.5m）→ 提前 1~1.5m 进入，让狗提前对直进梯线；
- **取消航点 z 升（stair_zone）作为触发依据**——大缓坡不再误切（当前唯一活跃触发，需迁移）。

**推荐组合**：`lidar step_flag 确认 OR 预扫描 riser 命中+距离窗`。两者都是"世界坐标 + 离散台阶"证据，均非 z 先验；已知地图给真机提前量，lidar 保换地图鲁棒。

## 四、出口判定（STAIR → CRUISE）

**几何完成（主）**：

- 后轴过末级 riser（沿切线投影 d < −0.05）且后轴均值轮高 ≥ 末级台面顶 + R − 0.02，**持续 0.05s**；
- 等价判据：4 轮全部"已过各自最近 riser 且轮高 ≥ 对应台面顶 + R − 0.02"。

**导航推进（辅）**：

- `next_idx` 推进（wp7 通过）或 s_cur > 末级 riser 弧长 + 1.0m。

**出口条件 = 几何完成 AND 导航推进**（防提前退出），加 0.1s 持续确认滞回。
**现状替换**：删除 `robot_xy[1] > 40.5` 绝对 y 判据（换地图失效）。

## 五、切换过渡（连续化）

- **入口窗**（riser 前 1.0~1.5m）：vx 从巡航值平滑插值到 `STAIR_WIN_VX`（1.8）；腿姿态从巡航半蹲向 BodyIK 爬梯目标过渡；
- **出口窗**（末级 riser 后 1.0m）：vx 从 `STAIR_WIN_VX` 平滑插值回巡航 vlim（入口 ramp 反向）；StairWBC → CarVMC 在出口窗末端切换；
- 切换瞬间腿目标差异由出口窗内 BodyIK 目标向巡航半蹲**线性过渡**吸收（先实现 vx 连续，姿态过渡视测试再加）；
- 全程无 vx 跳变、无推力中断（轴距 0.456m > 阶距 0.4m，前后轴永不同时 SWING）。

## 六、感知/规划层收尾清单（上轮验证的 4 处）

| # | 事项 | 现状 | 动作 |
|---|---|---|---|
| A | lidar 感知确认接线 | `update_mode` 未传 local_map，`_stair_confirmed` 永远 False（死代码） | LidarTerrain 增加 step_flag 派生，主循环把确认结果传给 `update_mode(local_map=...)` |
| B | 几何表单源化 | z 参考走硬编码 `STAIR_RISERS/TOPS`，布尔相位走预扫描 `stair_world`，双源 | 预扫描后自动回填 `_stair_tables()`（env 覆盖机制已有），换地图不失效 |
| C | STAIR 区无 MPPI | `mppi.plan` 无 mode 门控 | `fol.mode == 'STAIR'` 时直接用导航指令（vx, vyaw），不再调 MPPI |

## 七、实现顺序与验收

**实现顺序**：

1. B 几何表单源化 → 2. A 感知确认接线 + 入口判定 → 3. D vx 窗世界坐标化 → 4. C STAIR 无 MPPI → 5. StairWBC 执行层（终版文档）→ 6. 出口判定与过渡 → 7. 联调验收。

**验收标准**：

- wp6→8：入口在 wp7 前正确进入 STAIR，6 级爬完，出口自动回 CRUISE，wp8 通过；
- 全程腿 ≤48Nm / 轮 ≤13.5Nm、无弹射、vx 连续不归零；
- 鲁棒性测试：屏蔽已知地图后仅靠 lidar step_flag 也能触发（模拟换地图）。
