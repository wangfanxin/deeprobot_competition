## 2. 航点间巡航

### 状态
```text
SEGMENT_CRUISE -> 接近 wp -> WP_TURN -> SEGMENT_CRUISE
```

### 行为
- 从前一航点几乎静止出发。
- 段内快速加速。
- 接近下一航点时快速减速。
- 距 wp < 0.5m 时，如果 yaw 未对准下一段航向：
  - `refv = 0`
- 转向完成后：
  - 允许 `vx <= 0.2`
- 航点推进必须满足：
  - 距 wp < 0.5m
  - yaw 与下一段航向偏差 < 0.10 rad

### 参数
```bash
S10_AUTO_VMAX=2.5
S10_AUTO_LOOKAHEAD=2.0
S10_WP_ARRIVE_R=0.5
S10_WP_TURN_VX=0.2
S10_WP_TURN_YAW_DB=0.10
S10_MPPI_A_MAX=1.8
S10_MPPI_OMAX=2.5
S10_MPPI_W_GUIDE=0.5
```

## 3. BodyMPPI + CarVMC

- BodyMPPI：
  ```bash
  VMC_MPPI_N=512
  VMC_MPPI_H=20
  S10_MPPI_ADA=1
  ```
- 采样 dt=0.05，视界 1.0s。
- 摩擦锥约束。
- DBaS 自适应 sigma。
- nav 提供 guide_om / 曲率前馈。
- CarVMC 执行轮足扭矩。

## 4. 楼梯感知与切换

### 判定
- lidar 高程图检测路径上 riser。
- riser 高度阈值：
  ```bash
  S10_ELEV_STEP_TH=0.05
  S10_ELEV_MAX_STEP=0.50
  ```
- 高墙当障碍，不爬；只有 0.05~0.50m 台阶才爬。

### 接近减速
- 机体到首级 riser 直线距离 < 4m：
  - 开始猛减速。
- 目标速度：
  ```bash
  S10_TK1_VX=1.8
  ```

### 进入 RL-stair
- 同时满足：
  - 距离首级 riser <= 3m
  - 实际 `vx <= 1.8 m/s`
  - yaw 与楼梯方向偏差 < `S10_STAIR_ENTER_YAW_DB=0.15`

### 退出 RL-stair
- 四轮轮心高度均高于最后一节 riser 顶部。
- 留余量：
  ```bash
  S10_STAIR_WHEEL_CLEAR=0.05
  ```
- 切回 BodyMPPI+CarVMC。

### 回线
- 回线条件：
  - 到相邻航点连线横向偏差 < 0.5m
  - 机体 heading 与相邻航点连线 < 10°
- 满足后进入 SEGMENT_CRUISE。

---

## 5. TK1 / TK2

### TK1
- 楼梯前：
  - 检测到 riser
  - 减速
  - yaw 对准楼梯方向

### TK2
- 楼梯后：
  - 四轮过最高 riser 后切回
  - yaw 对准下一段 path heading
  - 回线后释放
