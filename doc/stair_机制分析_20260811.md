# Stair 技能机制分析（2026-08-11，v750）

## 当前状态

- **巡航（wp0→6）**：稳定通过 31.2s，各段均 <10s（v749 基线）。
- **Stair（wp6→7，六级台阶 0.063+5×0.125m）**：**未突破第一级**，三种执行层方案（WBC/FootPlace/CarVMC）均卡死或侧翻（历史 84+ 组 WBC 实验）。

## Stair 卡死根因链（v771~v792 共 21 组实验确认）

### 模式 A：CPG 抬轮 + WBC（dual 模式）

1. CPG 前轮抬轮（sl 0.5~0.9），前轮悬空（fn=0）。
2. WBC 按 `sl>0.3` 屏蔽抬轮腿 → 前轮不参与 wrench 求解 → 只有后轮支撑 → **单点支撑**（fn=[0,0,-25,0]）。
3. 后轮单点推力不足 → 车不前进 → CPG 相位冻结 → 前轮持续悬空卡死。

关键数据（v790）：卡死时前轮 wz=0.66（高于第一级台面+r=0.613），水平位置 y=37.65（棱前 0.29m），pitch≈0，后轮单点 -21N。

### 模式 B：纯滚动 + WBC（NO_LIFT）

1. 前轮贴地滚向棱边，但 v746 运动学地面（`terr=wheel_xyz-0.081`）是"自证"的：轮子悬空时 terr 跟随轮位，阻抗永远≈0，不纠正悬空。
2. WBC 给前轮"支撑力"（想前倾）但前轮无接触面 → 力推空气 → body 被推高 → **body 后倾**（pitch -0.2）→ 前轮更悬空。
3. 前轮距台面仅 0.003~0.008m 不接触（mujoco 接触间隙），压轮补偿不足。

关键数据（v785~788）：前轮 wz 0.61 vs 台面+r 0.613，差 0.003 不接触；pitch 持续后倾 -0.18~-0.27；fn 单轮或全 0。

### 模式 C：FootPlace IK 放轮（dual2 模式）

- CPG 抬轮 + IK 把轮放到台面+r → 放太高导致车身弹起翻转（roll 1.34→-2.75）。
- 历史 v704 同模式（姿态刚度×5 仍翻），确认是"轮目标-身体姿态正反馈"。

## 根因总结

1. **悬空抬轮中断推力**：CPG 抬轮时前轮离地（fn=0），轮速归零（v737），只剩后轮推 → 单点支撑死锁。
2. **WBC 支撑腿选择不基于物理接触**：按 sl 屏蔽而非接触检测，悬空前轮仍参与 wrench → 不物理的拉力/推力。
3. **运动学地面自证**：terr 跟随轮位，悬空轮不被纠正。
4. **缺少关键姿态**：前轮在台面时 body 必须前倾（前低后高），当前 WBC 无法产生前倾力矩（前轮无接触）。

## 文献方案（USC 2109.09934，真机 0.36m 台阶成功）

- **不悬空抬轮**：轮子持续驱动 τ=R·F_t，姿态前倾 + 腿伸长让轮心沿棱边滚动爬升，接触连续。
- **姿态优化**：解"前轮在台面/后轮在地面"的关键姿态（body pitch + CoM + 关节角），两个关键姿态线性插值。
- **QP 平衡控制**：腿力 QP（摩擦锥约束，力只能推），轮子单独滚动控制。

## 下一步建议

1. **实现 USC 式姿态插值**：楼梯区按"前轮距棱距离"插值 body pitch 和前腿伸长量（替代启发式 pitch），保证前轮接触台面时 body 前倾。
2. **WBC 支撑腿按物理接触选择**：用轮心高度 vs 地形目标（<0.01m）判接触，悬空轮不给 wrench 力。
3. **轮子持续驱动**：取消抬轮时轮速归零（v737），改"腿伸长辅助滚动"，保持 4 轮接触。
4. 若短期无法突破：先跳过 wp6→7，并行推进 wp7→33（急弯已部分验证到 wp15）。
